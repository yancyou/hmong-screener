1 · Collect Data

Records word productions and downloads them as a ZIP (audio + metadata). Nothing is uploaded — the audio stays in the browser until you press Download. Works on laptop, phone, or tablet.

Recording page: https://fluffy-cactus-f8de18.netlify.app/

The Collect Data tab.

Steps

  1. Speaker ID — type an ID (e.g. YX001). Required before downloading. Gender/group and Notes are optional.
  2. Pick a mode:
    • Single word — type the word, press Record, say it, press Stop. Record again for more takes; each take is saved separately.
    • Word list — type words separated by commas (e.g. dhia, dhiab, dhias), set the window (seconds per word) and lead‑in (countdown), press Start. Each word is shown, counted down, recorded for the fixed window, then it advances automatically.
  3. Recordings appear in the list below — play, re‑record, or delete any of them.
  4. Press Download ZIP to save <speaker>_<timestamp>.zip.

What's in the ZIP

  • <speaker>/<speaker>__<word>__take1.wav — one WAV per recording
  • metadata.csv — one row per recording (speaker, word, take, duration, timestamp, …)
  • metadata.json — the same information as JSON

2 · Batch Score

Upload a recorded session and score every recording at once. Each clip is compared with the reference recordings of the same word.

The Batch Score tab.

Steps

  1. Click Upload session ZIP and pick the ZIP from Collect Data (or Upload folder and pick the unzipped folder).
  2. The page reads the metadata and shows how many recordings were found.
  3. Set the Pass threshold, then press Score.
  4. Results show as a table — word, speaker, take, score, pass/below — with the mean and pass rate.
  5. Press Download CSV to save the table.

Reading the scores

ScoreA similarity value from −1 to 1. Higher means more similar to the reference recordings of that word.
PassScore ≥ threshold. Adjust the threshold to fit your data.
SkippedThe word has no reference recordings, or its audio file was missing.

3 · Live Eval

Compare a single reference with a single candidate.

The Live Eval tab.

  • Reference — type a word to use the built‑in reference recordings, and/or upload or record your own.
  • Candidate — upload a WAV or record one.
  • Press Compute Score.
