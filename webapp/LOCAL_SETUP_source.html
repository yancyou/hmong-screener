Hmong Audio Tool

Running it on your own computer — installation guide

UW‑Madison · Hmong XLS‑R

Two ways to install. Option A (Docker) is the recommended one — it builds a self-contained container, downloads the model for you, and needs nothing installed except Docker and Node. Option B (from source) is for when you want to edit the code.
You want to…Use
Just run the tool on your own machineOption A — Docker
Run it without internet after setupOption A — everything is baked into the image
Change the code, the UI, or the scoringOption B — from source

1 · Option A — Docker RECOMMENDED

Step 1 — Install Docker Desktop

Download it from docker.com, install, and open it. Wait until the whale icon in the menu bar says “Docker Desktop is running”.

Give Docker enough memory. Open Docker Desktop → Settings → Resources and set Memory to at least 8 GB. With the default 2 GB the container will be killed while the model loads.

Step 2 — Install Node.js

Needed once, to build the web page. Get the LTS version from nodejs.org (version 18 or newer).

Step 3 — Download the code

git clone https://github.com/tianyi0216/hmong_audio_software
cd hmong_audio_software

Step 4 — Add the reference recordings

Download reference_words.zip from the Google Drive folder and unzip it inside this project folder, so that all_data/ ends up next to api_similarity_server.py:

hmong_audio_software/
├── api_similarity_server.py
├── all_data/            ← the unzipped recordings go here
├── GUI/
└── Dockerfile

This is what fills the word-library dropdown (1143 words). Skip it and the tool still runs, but the dropdown will be empty.

Step 5 — Build the web page

cd GUI
npm install
npm run build
cd ..

Creates GUI/dist/. You only do this once, unless you change the interface.

Step 6 — Build the container

docker build -t hmong-audio .

This takes 10–20 minutes and downloads about 3 GB (PyTorch, the dependencies, and the 1.3 GB model checkpoint). It is quiet for long stretches — that is normal. You only do this once.

Step 7 — Start it

docker run -d --name hmong -p 8080:8080 hmong-audio

Then open http://localhost:8080 in your browser.

Everyday commands

WhatCommand
Stop itdocker stop hmong
Start it againdocker start hmong

Use a different port (if 8080 is taken)docker run -d --name hmong -p 8081:8080 hmong-audio

2 · Option B — From source

Use this if you want to edit the code. The backend and the web page run as two separate programs, in two terminal windows.

Step 1 — Install Python and Node

Python 3.10 (via Miniconda) and Node.js 18+ (nodejs.org).

Step 2 — Set up the Python environment

conda create -n hmong-env python=3.10 -y
conda activate hmong-env
pip install -r api_requirements.txt
pip install -e ./fairseq        # our modified fairseq

Step 3 — Set up the web page

cd GUI && npm install && cd ..

Step 4 — Get the model checkpoint

curl -L -o checkpoint_slim.pt \
  https://huggingface.co/tianyi0216/hmong-xlsr-checkpoint/resolve/main/checkpoint_slim.pt

~1.3 GB. Also add the reference recordings (Step 4 of Option A) if you have not already.

Step 5 — Run it

Terminal 1 — the backend (port 8000):

conda activate hmong-env
./run_similarity_server.sh checkpoint_slim.pt

Terminal 2 — the web page (port 5173):

cd GUI
npm run dev

Then open http://localhost:5173. Leave both terminals open while you use the tool.

3 · What to expect the first time

  1. The page opens immediately.
  2. The first score you request takes 2–3 minutes — the model is loading. Everything after that is fast.
  3. In the log you should see Loaded 424/424 tensors from checkpoint and Reference library: 1143 words. Those two lines mean it is healthy.

4 · If something goes wrong

What you seeWhat to do
The first score spins for a long timeNormal — the model loads on the first request (2–3 min). Check docker logs -f hmong.
The word dropdown is emptyall_data/ is missing or in the wrong place. It must sit next to api_similarity_server.py before you build the image. Fix it and rebuild.
The container keeps stopping by itselfDocker is out of memory. Docker Desktop → Settings → Resources → Memory → 8 GB.
port is already allocatedSomething else uses 8080. Use -p 8081:8080 and open localhost:8081.
The build fails while downloading the modelA network hiccup. Run docker build again — finished steps are cached.
ModuleNotFoundError: fairseq (Option B)You missed pip install -e ./fairseq, or the conda environment is not active.
Checkpoint not found (Option B)Pass the correct path: ./run_similarity_server.sh /full/path/to/checkpoint_slim.pt

5 · Letting others on your network use it

With Option A the container already listens on your whole network. Find your computer's local IP address (macOS: System Settings → Wi‑Fi → Details; Windows: ipconfig), then others on the same Wi‑Fi can open:

http://<your-ip-address>:8080

Example: http://192.168.1.42:8080. This works on your local network only — it is not reachable from the internet.
